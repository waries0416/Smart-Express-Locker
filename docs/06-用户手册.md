## 1. 先搞清楚你该用哪个入口

系统有三个入口，**按身份选**，不要混用：

| 你是 | 用哪个 | 地址 | 怎么进 |
|---|---|---|---|
| 收件人 / 寄件人 | 柜机触屏 或 手机 | 柜机屏幕 / `/m` | 触屏输取件码，或手机扫码 |
| 快递员 | 柜机触屏 或 手机 | 柜机屏幕 / `/m` | 点"快递员存件"，或手机切"我是快递员" |
| 系统管理员 | 管理端网页 | `/admin` | 账号口令登录 |

一条主线记住就够了：

> **快递员存件 → 系统给 6 位取件码 → 收件人凭码或扫码取件 → 超时则先缴费再开柜。**

## 2. 柜机触屏端（最常用）

### 2.1 首页长什么样

打开柜机屏幕，首页是一屏两卡：

- **左边**：一个二维码 + 倒计时（初始 120 秒）+ "🔄 刷新二维码"按钮
- **右边**：6 位取件码输入框 + "立即取件"按钮
- **底部**：`🚚 快递员存件`、`📖 使用帮助`

> 二维码不是取件码，是"**登录这台柜机**"的票据。用手机扫它，等于告诉柜机"我是谁"，之后就能看到自己名下的包裹。

### 2.2 用取件码取件（最直接）

1. 在右侧输入框输入 6 位取件码（如 `549548`）；
2. 点"立即取件"；
3. 屏幕弹出开柜引导，显示**柜体编号 + 格口号**（如 `CAB-001 · B05`）；
4. 对应格口弹开，30 秒倒计时内取走物品；
5. 关上柜门，点"完成"。

如果码输错了，会提示"取件码无效，请核对后重试"，不会开柜，也不会扣次数。

### 2.3 用手机扫码取件（不用记码）

1. 打开手机相机（或微信扫一扫），对准柜机屏幕上的二维码；
2. 手机会跳到本系统的手机页面，先登录（首次需输手机号 + 验证码）；
3. 点"确认登录"；
4. 柜机屏幕**自动**从二维码切换成你的头像和姓名，并列出你在这个柜体下的待取包裹；
5. 点某件包裹的"取件"，对应格口弹开。

> 若二维码显示"已过期"，点"🔄 刷新二维码"重新出码即可。柜机每 120 秒自动换一次码，这是防止别人拍下你的码事后使用。

### 2.4 超时了要先缴费

包裹免费保管 **48 小时**，超时按 **¥1.00/件** 收取保管费。

- 输码取件时，若该件已超时未缴费，屏幕**不会直接开柜**，而是弹出支付窗口显示金额（如 `¥1.00`）；
- 点"去支付"进入支付页（**页面会明确标注当前是"模拟支付"还是"支付宝沙箱"**，模拟支付不产生真实扣款）；
- 支付完成后系统自动开柜，无需重新输码。

> v1.1 变化：支付已经不是"点一下就当我付了"。现在是真实订单模型——后端建支付单、服务端算金额、
> 支付成功后取件闸门才放行。所以你**没法靠关掉页面绕过缴费**，取件接口会返回 402 拦住。
> 详见 `docs/08` §4。

### 2.5 快递员存件

1. 首页底部点 `🚚 快递员存件`；
2. 首次需登录：输工号（如 `E00001`）+ 手机号；
3. 进入存件页，依次填：
   - **收件人手机号**（必填，系统按它建档并通知收件人）
   - **收件人姓名**（选填）
   - **格口规格**：小件 ≤5kg / 中件 ≤10kg / 大件 ≤20kg
   - **重量**（kg）
   - **运单号**（可留空自动生成）
   - **备注**（选填）
4. 若这件是用户提前下的寄件单，在"匹配寄件单"框输**订单号或收件人手机号**，点"匹配"——规格与重量会自动带出且**不允许改**，保证与用户下单时一致；
5. 点"确认存件"；
6. 屏幕弹出取件码和格口号，**把取件码告诉收件人**（系统也会自动发通知）。

> 存件弹层只显示取件码，不再显示二维码。二维码在首页常驻，不用每次存件都扫。

### 2.6 快递员揽收（取走用户的寄件）

1. 首页底部点 `🚚 快递员存件` → 进入工作台；
2. 选"待揽收"，列出用户已下单、已放入柜中的寄件；
3. 核对后点"揽收"，格口弹开，取走包裹；
4. 系统把该寄件标记为"已揽收"，并通知寄件人。

### 2.7 查投递记录

工作台里点"投递记录"，可按时间查看自己近期存了多少件、分别进了哪个格口、当前状态（待取 / 已取 / 超时）。

### 2.8 不用了要退出

快递员工作台右上角有"退出登录"。**公用柜机上务必退出**，否则下一个人会以你的身份操作。

普通用户登录后，首页右侧会显示头像和"退出登录"；**120 秒无操作也会自动登出**。

## 3. 手机端（H5）

手机端地址形如 `http://192.168.1.20:5000/m`（由管理员提供）。用手机浏览器打开，或扫柜机二维码直接进。

### 3.1 登录

打开后是登录页，顶部可切「我是用户 / 我是快递员」：

**我是用户**
1. 输 11 位手机号；
2. 点"获取验证码"，等短信（演示环境验证码直接显示在页面上）；
3. 输 6 位验证码，点登录。

> 手机号没注册过也能登录——系统会自动为你建档，姓名默认为"用户" + 手机号后 4 位。

**我是快递员**
1. 切到"我是快递员"；
2. 输工号（如 `E00001`）+ 手机号；
3. 点登录，直接进入存件工作台（快递员不需要验证码）。

### 3.2 扫柜机二维码：确认登录

用**手机系统相机**（不是微信扫一扫也行）对准柜机屏幕的二维码，会打开一个确认页：

- 上方显示柜体编号与所在点位（如 `CAB-001 / 阳光花园小区`）；
- 中间显示你的姓名与脱敏手机号（如 `卢秀华（158****0001）`）；
- 下方显示"87 秒内有效"和两个按钮。

点"**确认登录**"，页面变成"已确认，请回柜机取件"，柜机在 1.5 秒内自动登录成你的身份。

> 若你还没登录，会先让你登录，登录完自动回到这个确认页。
> 若提示"二维码已过期"，回柜机点刷新再扫一次。

### 3.3 看待取包裹并开柜

登录后进入"手机取件"页：

1. 顶部显示"你好，XXX"；
2. 下方列出你名下**待取**的包裹，每张卡片显示：柜体 · 格口 · 规格、快递公司、存入时间；
3. 点卡片进入详情，可看到运单号、取件码、免费期剩余时间；
4. 点"**开柜取件**"，对应格口弹开。

超时的包裹卡片会标红并显示"需支付 ¥1.00"。点进去先支付，支付成功后自动开柜。

### 3.4 门没开 / 关不上，重新开门

- 格口没弹开：在包裹详情页点"**重新开门**"。该功能只对**本人、刚取走 5 分钟内**的包裹有效——超时会提示"已超过 5 分钟，如需帮助请联系现场工作人员"，避免被当成万能开锁。
- 取完东西柜门关不上：先把物品取出、清空格口，再点"重新开门"关门，然后点"完成"。

### 3.5 寄件下单

1. 底部切到"寄件"；
2. 填寄件人、收件人姓名与手机号；
3. 选快递公司、格口规格（小/中/大）；
4. 填物品重量与备注；
5. 提交后系统给出**订单号**与**揽收码**，并自动分配一个格口；
6. 到柜机把包裹放进该格口、关好门——快递员揽收时会取走，格口随即释放。

> 揽收码可以给快递员，用于快速匹配这张寄件单（也可以只报手机号）。

> 下单后未揽收前可以"撤回"：在"我的"里找到该订单点撤回，包裹状态变为"已撤回"。

### 3.6 我的

底部"我的"页可看：
- 全部包裹记录（收件 + 寄件，含已取/已撤回）；
- 消息通知（站内信）；
- 退出登录。

### 3.7 AI 寄件助手（v1.1 新增）

在手机端"寄件"页点「AI 帮我看看」，或在底部切「AI 助手」。

**能问什么**：这东西能不能寄、要怎么包、选哪个规格、要不要自己带包装材料。

**怎么用**：

1. 描述你要寄的东西，例如"一个玻璃杯和两本书"；
2. 点"获取建议"，等待约 1 秒；
3. 页面给出四块结果：
   - **禁寄/限寄**（红色）：如"锂电池 · 航空禁运"——**这类东西不要拿去寄**；
   - **需要特别处理**（黄色）：如"玻璃杯 · 易碎需缓冲"；
   - **打包步骤**：一步一步告诉你怎么包；
   - **建议规格 + 材料清单**：选小/中/大哪一档，快递员要带什么。
4. 点"按建议填单"，规格自动带到寄件表单里。

**关于右上角的小角标**（重要）：

| 角标文字 | 含义 |
|---|---|
| `AI 推荐` | 本次结果来自 DeepSeek 模型 |
| `规则推荐` | 本次结果来自系统内置规则（没配 API Key，或模型暂时不可用） |

两种都能用，只是"规则推荐"覆盖面窄一些。页面会同时显示"结果仅供参考，以快递员/承运商审核为准"，**这句话不是免责声明凑字数——禁寄判断最终以承运商为准**。

**还能问问题**：在 AI 助手页直接输入"超时了怎么取件""取件码输错了怎么办"，会给出对应解答。

### 3.8 地图找柜（v1.1 新增）

在"寄件"页点「选柜」，或在底部切「找柜」。

1. 首次使用浏览器会问要不要允许定位，点"允许"；
2. 页面画出附近的快递柜，每台下面标注**距离**（如 `350 米`）与**空闲格口数**；
3. 排在最上、带「推荐」标记的那一台，是系统综合"距离近 + 有空位"算出来的**首选柜**；
4. 点某台柜子看它的大/中/小格口各剩几个，再点"选这台寄"。

**没允许定位怎么办**：页面会退回成"按柜号/地点搜索"的列表，只是不显示距离，功能不受影响。

**地图加载不出来**：如果页面提示地图不可用，说明这台机器没配高德 Key，系统会自动切成"列表 + 示意图"，**照样能选柜**。

### 3.9 支付中心（v1.1 新增）

超时缴费、寄件付费都会进到支付页。

**页面会明确告诉你现在是什么渠道**：

| 页面标识 | 含义 | 会不会真扣钱 |
|---|---|---|
| **模拟支付** | 演示用的模拟渠道（默认） | **不会**。这是课程演示环境 |
| 支付宝沙箱 | 接的是支付宝沙箱环境 | 不会。沙箱是支付宝提供的测试环境 |

**流程**：

1. 页面显示应付金额（这个金额是**服务端算的**，不要试着手动改——改了不起作用）；
2. 点"确认支付"；
3. 支付成功后页面显示完成时间，回到取件页点"开柜取件"。

**注意两件事**：

- 支付单有**有效期（默认 10 分钟）**，过期后要重新下单；
- 同一笔业务重复点"支付"不会生成第二张单，会复用原来那张（这是防重复扣款）。

在"我的 → 支付记录"里能查到自己的每一笔支付。

## 4. 管理端（管理员）

### 4.1 登录

浏览器打开 `http://<服务器地址>/admin`，会自动跳到登录页。输账号口令（默认 `admin` / `admin123`）后进入看板。

> 会话靠服务端 Cookie 维持，**关闭浏览器或点"退出登录"即失效**。未登录时直接输后台地址会被跳回登录页——这是服务端拦截，不是前端遮罩。

### 4.2 数据看板

登录后默认页，包含：

| 区块 | 看什么 |
|---|---|
| 顶部 KPI（11 张卡片） | 快递公司数、快递员数、用户数、快递柜/格口数、包裹总数（含今日存/取）、待取件（已存）、格口占用（空闲/故障）、异常包裹（超时/退回/异常）、待取件记录、待送记录（待揽收）、已揽收 |
| 包裹状态分布 | 已存件 / 已取件 / 已超时 / 异常 / 已退回 / 待揽收 / 已揽收 七态占比（环形图） |
| 各柜体吞吐量 Top 10 | 哪些柜子最忙 |
| 近 14 天存取趋势 | 存件与取件的日曲线 |
| 异常类型分布 | 超时、破损、错格、超重、漏取 各多少 |
| 快递公司排名 | 各公司存件量与超时率 |

### 4.3 业务操作

管理员专属的高危操作区，用于兜底处理。操作方式：先填**包裹 ID**（`package_id`），再点对应按钮。

| 操作 | 用途 | 注意 |
|---|---|---|
| 强制超时 | 把某件包裹直接置为"超时"，用于演示计费 | 仅"待取"状态可操作 |
| 退回快递员 | 用户长期不取，退回 | 会释放格口并写异常流水 |
| 登记异常 | 记录破损 / 错格 / 超重 / 漏取 / 超时，必要时把包裹置为"异常" | 选异常类型、填备注后提交；异常件不能取件，需先处理 |

### 4.4 通知中心

看所有通知的流水：类型、接收人、渠道（短信 / 站内信 / 推送）、投递状态、失败原因、重试次数。

- **重试**：单条失败可点"重试"手动重投，死信也能复活；
- **统计**：按状态汇总，判断是否有积压；
- **测试**：发一条测试通知，验证渠道连通。

### 4.5 基础数据维护

以下五项都是标准的"列表 + 新增 / 编辑 / 删除"：

| 页签 | 维护什么 | 删除时注意 |
|---|---|---|
| 快递公司 | 公司编码、名称、客服电话 | 有快递员或包裹引用时会被拦住 |
| 快递员 | 工号、姓名、手机号、所属公司 | 有包裹引用时会被拦住 |
| 用户 | 姓名、手机号 | 有包裹时会被拦住 |
| 快递柜 | 柜体编号、点位地址、状态（正常/维护） | 有格口时会被拦住 |
| 格口 | 所属柜体、格口号、规格 | 有包裹时会被拦住 |

删除前系统会先提示"关联了多少条记录"，可选择"级联清理"一并删除，或取消操作。

### 4.6 包裹管理与两类记录查询

按条件筛包裹：运单号、取件码、手机号、状态、柜体、时间范围。列表可直接看每件的当前状态与存放时长。

分"收件记录"和"寄件记录"两个视角，寄件记录还能看到"是否已揽收"。

### 4.7 格子矩阵与远程开锁

选一个柜体，看到它的**物理格口矩阵**（按柜体实际排列，不是列表）：

| 颜色 | 含义 |
|---|---|
| 绿 | 空闲 |
| 蓝 | 占用（在柜包裹） |
| 红 | 故障 |
| 灰 | 维护 |

点任一格口可看详情：当前包裹、存入时长、是否需要缴费。必要时可**远程强制开锁**（用户电话求助时用）。

### 4.8 备包装与支付流水（v1.1 新增）

**备包装任务**：用户用 AI 助手算出包装方案后，系统会给对应快递员生成一条"备包装"任务。

| 看什么 | 说明 |
|---|---|
| 任务列表 | 每条显示包裹运单号、柜体格口、建议规格、状态（待处理/已完成/已取消） |
| 材料清单 | 这条任务需要带哪些材料、各几件 |
| 材料台账 | 每种材料的当前库存与低库存阈值；**库存 ≤ 阈值的行会标红**，表示该补货了 |

操作：快递员在手机端点"完成备包装"即置为已完成。管理员可查全部任务。

> 材料名称与数量在任务生成时**快照保存**。之后改材料台账的名字或单位，不影响历史任务里记的清单。

**支付流水**：能看到所有支付单——

| 列 | 含义 |
|---|---|
| 商户订单号 | 形如 `P20261118001` |
| 业务类型 | `OVERTIME`（超时保管费）/ `SEND`（寄件费） |
| 金额 | **服务端快照金额**，不是前端传的 |
| 渠道 | `模拟支付` / `支付宝沙箱` |
| 状态 | `PENDING` / `SUCCESS` / `FAILED` / `CLOSED` |
| 创建时间 / 支付时间 | — |

可按状态、渠道、业务类型筛选。

### 4.9 退出

右上角"退出登录"。公用电脑上务必退出。

## 5. 常见问题

### 收件人相关

**Q：取件码忘了怎么办？**
A：用手机扫柜机二维码登录，名下待取包裹会直接列出，不需要取件码。也可以联系管理员在后台按手机号查。

**Q：柜门没开？**
A：① 确认格口号与屏幕显示一致；② 在手机端包裹详情点"重新开门"（仅限本人、取件后 5 分钟内）；③ 仍不行请联系管理员远程开锁。

**Q：超时费怎么算？**
A：免费保管 48 小时，之后每件 ¥1.00。缴费在柜机或手机端完成，付完立即开柜。

**Q：能让别人代取吗？**
A：可以。把 6 位取件码告诉对方即可，取件码不绑定手机号。

**Q：柜机上的二维码是干什么的？**
A：是"登录这台柜机"的票据，不是取件码。扫它之后柜机认识你，才能列出你的包裹。有效期 120 秒，过期自动刷新。

**Q：扫码后提示"已过期"？**
A：柜机每 120 秒换一次码（防拍照留存）。回柜机点"🔄 刷新二维码"再扫。

### 快递员相关

**Q：存件时提示"该规格格口已满"？**
A：换一个规格，或换一个柜体。后台"格子矩阵"能看到哪个柜体还有空位。

**Q：匹配寄件单后规格改不了？**
A：这是设计如此。用户在寄件下单时已确定规格并据此分配格口，快递员必须沿用，否则会出现"格口装不下"或"计费不一致"。

**Q：存完件收件人没收到短信？**
A：通知是异步的，最多延迟 15 秒；若长期未收到，让管理员在"通知中心"看该条记录的投递状态与失败原因。

### 管理员相关

**Q：后台登录后刷新又回登录页？**
A：多半是访问地址混用（一会儿 `localhost`、一会儿 `127.0.0.1`、一会儿 IP）。Cookie 按域名隔离，统一用一个地址访问即可。

**Q：删除公司/快递员时提示有关联记录？**
A：系统在做外键保护。可选择"级联清理"一并删除关联记录，或先把关联记录处理掉再删。

**Q：通知一直显示"待投递"？**
A：检查后台通知服务是否在运行（`NOTIFY_WORKER` 是否被关掉）；也可在"通知中心"点"手动投递"触发一轮。

**Q：想看某个格口现在装了什么？**
A：进"格子矩阵"，选柜体后点该格口，右侧抽屉会显示包裹详情与存放时长。

## 6. 术语表

| 术语 | 含义 |
|---|---|
| 取件码 | 6 位数字，存件时生成，凭它开柜 |
| 运单号 | 快递公司的包裹单号，系统也支持自动生成 |
| 格口 | 柜体里的一个物理小格子，有大小规格（小/中/大） |
| 柜体 | 一台快递柜，编号形如 `CAB-001` |
| 免费期 | 存件后的免费保管时长，本系统为 48 小时 |
| 超时费 | 超过免费期后的保管费，本系统为 ¥1.00/件 |
| 登录票据 | 柜机屏幕上二维码的内容，用于把手机身份绑到柜机，2 分钟有效、一次性 |
| 揽收 | 快递员从柜中取走用户的寄件包裹 |
| 站内信 | 系统内的消息，登录后在手机端"我的"里看 |
| 幂等 | 同一次操作重复提交不会产生重复结果（如网络重试不会开两次柜） |
